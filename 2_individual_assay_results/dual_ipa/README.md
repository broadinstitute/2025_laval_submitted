# Notes for the DUAL-IPA assay

The DUAL-IPA assay measures the difference in abundance between variant and reference alleles from the same gene. 

## Files in 1_inputs
There are two types of data inputs:
- **cherry_picking_files**: these are the files used to program the FACS machine. They relate particular source and desitination wells and plates to orf_ids and mut_ids.
- **raw_inputs**: this directory is created by running the analysis scripts and downloads raw FACS data from Zenodo at (this location)[https://zenodo.org/records/15000710].

The analysis additionally takes as inputs the allele collection metadata from the **1_allele_collection** directory.

## Using 2_analysis
Navigate into the `2_analysis` directory and create the dual-ipa Python virtual environment with all dependencies:
```
mamba create --name dual-ipa --file env-reqs.txt
mamba activate dual-ipa
```

Python notebooks and scripts are numbered in the order that they should be run to reproduce all of the output files. Python scripts without numeric prefixes contain functions that are imported by the numbered files. Each notebook starts with a description of the analysis tasks that it performs, and contains extensive comments throughoupt.



## Files in 3_outputs
The analysis scripts create four files:

- **dualipa_experimental_layout.csv**: this maps plate and wells from the FACS experiment to allele metadata. 
- **facs_single_cell.parquet**: a data frame with unfiltered, single-cell FACS data. Various summary stats are appended and GFP values equal to zero were replaced with the minimum measured value to avoid undefined log10() transformed values. This file is too big to track in GitHub and so is generated by the **2_compile_facs.ipynb** notebook. 
- **DUALIPA_mean_zscore.tsv**: abundance change z-scores between variant alleles and their matched reference alleles, computed using mean aggregation across replicates.
- **DUALIPA_median_zscore.tsv**: abundance change z-scores between variant alleles and their matched reference alleles, computed using median aggregation across replicates.
