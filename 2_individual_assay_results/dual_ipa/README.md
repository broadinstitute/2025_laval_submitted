# Notes for the DUAL-IPA assay

The output file **facs_single_cell.parquet** is >200MB and so it is not tracked in the repository. To generate it for downstream analysis, run the **2_compile_facs.ipynb** notebook in the **2_analysis** directory. This will download the raw FACS data from Zenodo at (this location)[https://zenodo.org/records/15000710] and compile it into a single data frame, along with some computed summary statistics.
