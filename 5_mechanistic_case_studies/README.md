# Notes on the MVK functional assay
The MVK gene showed up as particularly interesting in the profiling data and so it was run through a follow-up functional growth assay.


## Files in 1_inputs
The assay readout is a binary growth or no growth score, based on visually examining images of the yeast colonies. The images are in **MVK - functional assay.key** and the binary scores are in **mvk_functional_assay.csv**.
