# Processed files information

```VarChampSeqConfirmationResult_final_call.tsv``` is processed by ../2_analysis/1_process_clinvar_gnomad.ipynb to call the final sequence confirmation results for VarChAMP allele collection.

```varchamp_seq_confirm_alleles_clinvar_gnomad.tsv``` is processed by ../2_analysis/1_process_clinvar_gnomad.ipynb to merge the ClinVar and gnomad annotation to allele collection

```varchamp_seq_confirm_alleles_clinvar_gnomad_dbnsfp_struc_scores.tsv``` is processed by ../../4_compare_ai_scores/2_analysis/3_ai_var_predictors_analyses.ipynb to merge the dbnsfp database and AF2 predicted structural scores (pLDDT and RSA) to allele collection
